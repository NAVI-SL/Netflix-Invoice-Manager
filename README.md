# Netflix Invoice Manager

Netflix Invoice Manager is a sleek, web-based application designed to help you effortlessly manage shared subscriptions and track pending collections among a pool of members.

## Features

- **Dashboard Overview:** Get a quick glance at your active monthly bill summary, total invoices generated, and total collected amount.
- **Invoice Creation:** Easily draft new billing splits for your subscription group.
- **Payment Tracking:** Track which members have paid and who is still pending. Mark payments as complete with a single click.
- **WhatsApp Reminders:** Automatically generate and send payment reminders to pending members via WhatsApp.
- **Invoice History:** Keep a record of all past invoices and collections.
- **Settings:** Configure default bank details and user preferences.
- **Local Storage:** All data is securely stored locally in your browser—no backend required!

## Tech Stack

- **HTML5:** Semantic structure.
- **Tailwind CSS:** Utility-first CSS framework for rapid UI development and styling.
- **Vanilla JavaScript:** Core logic and state management.
- **Google Fonts:** Utilizing 'Inter' and 'Montserrat' for typography.
- **Material Symbols:** Google's Material icon library.

## Getting Started

Since this is a client-side application, getting started is incredibly simple:

1. Clone or download the repository to your local machine.
2. Open the project folder.
3. Double-click `index.html` to open it in your preferred web browser.
4. Start creating your first invoice!

## File Structure

- `index.html` - Dashboard & Overview
- `create-invoice.html` - Form to setup a new invoice/split
- `invoice-history.html` - List of all past invoices
- `invoice-preview.html` - Preview of a generated invoice
- `settings.html` - User preferences and bank details configuration
- `js/store.js` - LocalStorage-based state management utility
